# MegaViewer

**MegaViewer** --- приложение для удобного просмотра и навигации по
контенту в облачном сервисе **MEGA** Без входа в аккаунт.

Приложение позволяет открывать публичные ссылки MEGA, просматривать
содержимое папок и файлов, а также использовать потоковое
воспроизведение видео.

## Возможности

-   📁 Просмотр файлов и папок из MEGA.
-   🔗 Открытие публичных ссылок MEGA.
-   🎬 Просмотр и потоковое воспроизведение видео.
-   🖼️ Удобная работа с медиаконтентом.
-   🔎 Поиск по файлам и вложенным папкам.
-   ↕️ Сортировка содержимого.
-   🕘 История недавно открытых коллекций.
-   💾 Локальный кэш для более удобной работы.
-   🌙 Минималистичный тёмный интерфейс.
-   🚪 Работа с публичными ссылками без необходимости входа в аккаунт.

## Интерфейс

MegaViewer создан с упором на простую навигацию и быстрый доступ к
медиаконтенту.

Основные элементы интерфейса:

-   боковая панель с недавними коллекциями;
-   поле для вставки публичной ссылки MEGA;
-   категории файлов: **Все файлы**, **Фото**, **Видео**, **Папки**;
-   поиск по текущей коллекции;
-   сортировка файлов;
-   просмотр содержимого в едином интерфейсе.

3.  Установите необходимые зависимости согласно используемому стеку

> зависимости от версии и используемых технологий проекта.

## Использование

1.  Запустите **MegaViewer**.
2.  Скопируйте публичную ссылку на папку или файл в MEGA.
3.  Вставьте ссылку в поле **«Вставьте ссылку MEGA»**.
4.  Нажмите **«Открыть ссылку»**.
5.  Просматривайте файлы и папки через интерфейс приложения.

Также можно открыть **демо-коллекцию**, чтобы ознакомиться с интерфейсом
без добавления собственной ссылки.
